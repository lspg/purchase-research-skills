# Modèle de document de synthèse pré-achat

## Couverture
Produit recherché, objectif, date de recherche.

## 1. Cahier des charges
### Obligatoire
### Important
### Souhaitable
### Hors besoin

## 2. Marché et familles de solutions
Expliquer brièvement les architectures possibles et pourquoi certaines sont écartées.

## 3. Shortlist
Tableau comparatif lisible.

## 4. Comparaison par usages/scénarios
Un tableau par scénario si nécessaire.

## 5. Fiches produits finalistes
Pour chaque produit :
- photo officielle si disponible ;
- prix daté ;
- URL ;
- spécifications discriminantes ;
- performances réelles ;
- SAV/garantie ;
- accessoires ;
- points forts ;
- limites ;
- inconnues.

## 6. Accessoires et écosystème
Inclure prix et compatibilité.

## 7. Coût total
Produit nu / configuration minimale / configuration recommandée / coût de possession si pertinent.

## 8. Promotions et alternatives
Identifier les vraies bonnes affaires sans laisser la remise dominer le choix.

## 9. Questions encore ouvertes
Informations pouvant inverser la décision.

## 10. Conclusion
2 à 4 options maximum :
- option la plus cohérente pour scénario A ;
- option pour scénario B ;
- option valeur/prix si utile.

Ne pas masquer les compromis derrière une note globale.
